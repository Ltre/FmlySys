验证手工菜单是否推送 VIEW 事件

  1. 在公众号后台手工创建一个“跳转网页”菜单，URL 填写下方测试地址中的公网域名和路径。
  2. 保存并发布菜单；菜单更新可能需要几分钟生效。
  3. 用微信用户打开公众号会话，点击该菜单，然后回到此页观察事件列表。

建议的菜单目标路径

https://你的公网域名{{.WeChatMenuTestPath}}

该地址只显示健康检查结果，用于触发菜单跳转，不登录、不传递身份。事件中的 EventKey 会记录此 URL，FromUserName 会显示公众号 OpenID。

注意：目标 URL 中的 query 参数对所有点击者相同，不能用作用户身份。事件回调与浏览器打开 URL 是两条独立请求。
